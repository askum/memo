# 📝 데스크톱 메모 (Desktop Memo)

파이썬 환경 종속성이나 검은 화면 렌더링 문제 없이, **어떤 PC(Mac / Windows)에서든 즉시 실행되는 폴더 트리형 메모 프로그램**입니다.
외부 패키지 설치(`npm install`)가 전혀 필요 없는 순정 Node.js 표준 라이브러리 기반으로 제작되었습니다.

---

## ✨ 핵심 기능

1. **📂 좌측 창: 작업 폴더 지정 및 계층형 파일 트리**
   - **`[폴더 변경]`**: 메모를 저장할 로컬 폴더(예: 문서, 클라우드 폴더 등)를 선택하여 작업 공간으로 지정
   - **트리 뷰**: 하위 폴더와 파일(`.md`, `.txt`)을 계층 구조(`📁 폴더`, `📝 파일`)로 탐색
   - **`[+ 새 메모]`**: 현재 선택한 폴더에 새 메모 파일 생성
   - **`[+ 새 폴더]`**: 하위 폴더 생성
   - **이름 변경(✏️) & 삭제(🗑️)**: 마우스 호버 시 항목별 즉시 편집/삭제
   - **실시간 검색**: 상단 검색창에 입력하면 트리 항목 실시간 필터링

2. **📝 우측 창: 실시간 메모 에디터**
   - 좌측 트리에서 파일을 클릭하면 즉시 열려 내용 수정
   - **실시간 자동 저장**: 글을 작성하면 0.5초 뒤 자동으로 파일에 저장되며 상단에 `💾 저장됨` 상태 표시
   - 수동 저장 단축키: `Cmd + S` (Windows: `Ctrl + S`)
   - 하단 정보: 글자 수, 단어 수, 현재 줄/열 번호, 마지막 저장 시각 표시
   - 좌우 창 크기 조절: 가운데 구분선(스플리터)을 마우스로 드래그하여 조절 가능

## 🚀 실행 방법 (마우스 더블 클릭)

### 방법 1. 로컬 앱 실행 (가장 추천)
- **🍎 Mac**: 파인더에서 **[`MyMemo.command`](file:///Users/askum/workspace_gemini/memo/MyMemo.command)** 더블 클릭
- **🪟 Windows**: 탐색기에서 **`MyMemo.bat`** 더블 클릭
- *(터미널에서 직접 실행할 경우: `node server.js` 또는 `./run.sh`)*

실행 즉시 로컬 서버가 시작되고 기본 브라우저에 데스크톱 메모 화면이 바로 나타납니다.

---

### 방법 2. 설치가 아예 없는 완전 무설치 브라우저 실행
- **[`standalone.html`](file:///Users/askum/workspace_gemini/memo/standalone.html)** 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 더블 클릭하여 엽니다.
- `[폴더 열기]` 버튼을 눌러 메모 폴더를 지정하면 로컬 파일과 바로 연동되어 동작합니다.
