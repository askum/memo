# 📝 데스크톱 메모장에 오신 것을 환영합니다!

왼쪽 창에서 폴더를 지정하고, 원하는 위치에 파일이나 새 폴더를 바로 만들어보세요.

---

### 📌 다른 메모로 바로 이동하는 링크 기능:
메모 본문에 다른 메모의 이름을 `[[메모제목]]` 형태로 적어두면 언제든지 클릭 한 번으로 해당 메모로 바로 이동할 수 있습니다!

- **예시 링크**: [[회의록.md]]
- **링크 삽입**: 우측 상단 `[🔗 링크 삽입]` 버튼 또는 `Cmd+K` (Windows: `Ctrl+K`) 단축키를 누르면 전체 메모 목록에서 바로 선택할 수 있습니다.
- **상단 연결 바**: 본문에 연결된 메모들이 에디터 상단 `[🔗 연결된 메모: 📄 회의록.md ↗]` 파란색 버튼으로 항상 명확히 표시됩니다.
- **이동 방법**:
  1. 상단에 표시된 `[📄 회의록.md ↗]` 버튼 클릭 (가장 쉬움!)
  2. 본문에서 `[[회의록.md]]` 글자를 **더블 클릭**하거나 `Cmd+클릭` (Windows: `Ctrl+클릭`)

---

### 📌 기본 사용법:
1. **폴더 선택**: 좌측 상단 `[폴더 변경]` 버튼으로 원하는 메모 저장 위치를 지정할 수 있습니다.
2. **새 메모/폴더 생성**: `[+ 📝 새 메모]`, `[+ 📁 새 폴더]` 버튼을 누르면 현재 선택된 위치에 바로 생성됩니다.
3. **실시간 자동 저장**: 글을 입력하면 0.5초 뒤 안전하게 자동 저장됩니다. (`Cmd+S` / `Ctrl+S` 수동 저장 가능)
