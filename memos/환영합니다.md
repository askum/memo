# 📝 폴더형 데스크톱 메모장에 오신 것을 환영합니다!

왼쪽 창에서 폴더를 지정하고, 원하는 위치에 파일이나 새 폴더를 바로 만들어보세요.

### 📌 주요 사용법:
1. **폴더 선택**: 좌측 상단의 [📂 폴더 변경] 버튼으로 원하는 메모 저장 위치를 지정할 수 있습니다.
2. **새 메모 생성**: 상단 `[+ 📝 새 메모]` 버튼을 누르거나 폴더에서 우클릭하여 새 마크다운(.md) 또는 텍스트(.txt) 파일을 생성합니다.
3. **새 폴더 생성**: 상단 `[+ 📁 새 폴더]` 버튼으로 하위 폴더를 자유롭게 만듭니다.
4. **자동 저장**: 우측 창에서 메모를 입력하면 자동으로 실시간 저장됩니다. (`Cmd+S` 또는 `Ctrl+S` 수동 저장도 가능)
5. **우클릭 메뉴**: 폴더나 파일을 우클릭하여 이름 변경, 삭제, 파인더/탐색기 열기를 사용할 수 있습니다.
