📝 데스크톱 메모장에 오신 것을 환영합니다!

어떤 PC(Windows / macOS)에서든 설치 없이 즉시 실행되는 초경량 폴더 기반 데스크톱 메모 프로그램입니다.
Node.js 표준 라이브러리(Zero Dependencies)만으로 동작하여 매우 빠르고 가볍습니다.

---

📌 시작하기 & 예시 메모 둘러보기 (더블 클릭으로 이동):
- 개인 메모 예시: [[개인/테스트]] (👈 더블 클릭해 보세요!)
- 업무 메모 예시: [[업무/테스트]] (👈 더블 클릭해 보세요!)

---

✨ 주요 기능 안내

1. 📂 좌측 탐색기 & 마우스 드래그 앤 드롭 이동
• 마우스 드래그 이동: 파일이나 폴더를 마우스로 끌어서 다른 폴더 위로 놓으면 즉시 이동됩니다. 빈 공간으로 놓으면 최상위 폴더로 이동합니다.
• 기본 .txt 전용 보기: 텍스트 메모만 깔끔하게 보거나, 상단 [🗂️ 전체] 버튼을 눌러 엑셀, PDF, 이미지 등 모든 파일을 확인할 수 있습니다.
• 작업 폴더 변경: 상단 [폴더 변경] 버튼으로 컴퓨터 내 원하는 폴더(문서, 클라우드 동기화 폴더 등)를 언제든 지정할 수 있습니다.
• 빠른 관리: 항목에 마우스를 올리면 새 메모(+📝), 새 폴더(+📁), 이름 변경(✏️), 삭제(🗑️) 버튼이 나타납니다.
• 실시간 검색: 상단 검색창에 단어를 입력하면 일치하는 메모만 즉시 필터링됩니다.

2. 📊 엑셀 및 외부 파일 연동 & 더블 클릭 실행
• 본문에 [[보고서.xlsx]] 또는 [[자료.pdf]] 형식으로 링크를 걸어둘 수 있습니다.
• 탐색기에서 파일을 본문으로 드래그하면 링크가 자동으로 삽입됩니다.
• 링크를 더블 클릭하면 컴퓨터에 설치된 Excel, PDF 뷰어, 한글, 이미지 뷰어 등 전용 프로그램으로 즉시 실행됩니다.

3. 📝 실시간 메모 에디터 & 스마트 자동 저장
• 글을 작성하면 1초 유휴 시(또는 연속 입력 시 3초 주기) 백그라운드에서 파일에 안전하게 자동 저장됩니다.
• 실제로 변경되었을 때만 주황색 점(●)과 '수정 중' 상태가 표시되며, 원래대로 되돌리면 즉시 '저장됨'으로 복구됩니다.
• 하단 상태바에서 글자 수, 단어 수, 커서 위치(줄/열), 인코딩(UTF-8)을 실시간으로 확인할 수 있습니다.

4. 🔍 단어 찾기 및 바꾸기 (Find & Replace)
• 단축키: Ctrl + F (찾기), Ctrl + H (찾기 및 바꾸기)
• 대/소문자 구분(Aa), 일치 개수 실시간 카운트, 이전(▲)/다음(▼) 일치 항목 탐색, 개별 바꾸기 및 문서 전체 바꾸기를 지원합니다.

5. 🔢 줄 번호 & 자동 줄바꿈 토글
• 하단 상태바의 [🔢 줄 번호] (단축키 Alt + L)를 눌러 줄 번호를 켜고 끌 수 있습니다.
• [↩ 자동 줄바꿈] (단축키 Alt + Z)을 눌러 창 너비에 맞춘 자동 줄바꿈을 켜고 끌 수 있습니다.

6. 🔗 메모 간 위키 링크 & 탐색 히스토리
• 본문에 [[메모이름]]을 작성하고 더블 클릭하면 해당 메모로 즉시 이동합니다.
• 상단 [🔗 링크 삽입] (단축키 Ctrl + K)으로 다른 메모나 외부 파일을 손쉽게 링크할 수 있습니다.
• 상단 [◀] / [▶] 버튼이나 단축키(Alt + ← / →)로 웹 브라우저처럼 이전/다음 메모로 편리하게 이동할 수 있습니다.

7. 🌓 다크 모드 / 라이트 모드
• 좌측 상단 [🌙] / [☀️] 버튼으로 테마를 전환할 수 있으며, 운영체제 기본 설정을 자동 인식합니다.

---

⌨️ 키보드 단축키 모음

• 단어 찾기 (Find): Ctrl + F (Mac: Cmd + F)
• 단어 바꾸기 (Replace): Ctrl + H (Mac: Cmd + H)
• 메모 즉시 저장: Ctrl + S (Mac: Cmd + S)
• 줄 번호 켜기/끄기: Alt + L (Mac: Option + L)
• 자동 줄바꿈 켜기/끄기: Alt + Z (Mac: Option + Z)
• 메모 링크 삽입: Ctrl + K (Mac: Cmd + K)
• 새 메모 생성: Ctrl + N (Mac: Cmd + N)
• 작업 폴더 변경: Ctrl + O (Mac: Cmd + O)
• 이전 메모로 뒤로가기: Alt + ← (Mac: Option + ←)
• 다음 메모로 앞으로가기: Alt + → (Mac: Option + →)
• 기능 안내 / 도움말: F1
