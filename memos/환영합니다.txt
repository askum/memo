📝 데스크톱 메모장에 오신 것을 환영합니다!

어떤 PC(Windows / macOS)에서든 설치 없이 즉시 실행되는 초경량 폴더 기반 데스크톱 메모 프로그램입니다.
Node.js 표준 라이브러리(Zero Dependencies)만으로 동작하여 매우 빠르고 가볍습니다.

---

📌 빠른 시작:
- 상단 [새 메모] 버튼이나 단축키(Cmd+N / Ctrl+N)로 언제든 새 메모를 작성할 수 있습니다.
- 상단 [작업 폴더 변경] 버튼으로 내 컴퓨터의 원하는 작업 폴더(문서, 드라이브 등)를 선택하면 기존 메모와 폴더들을 있는 그대로 불러와 안전하게 관리할 수 있습니다.

---

✨ 주요 기능 완벽 가이드

1. 📂 스마트 파일 & 폴더 탐색기 (검색 기능 대폭 강화)
• 하위 폴더 파일 완벽 검색: 깊은 하위 폴더 안에 있는 메모도 검색 시 일치 항목이 있는 모든 부모 폴더가 자동으로 열리며 즉시 찾아줍니다.
• 파일명 & 확장자 통합 검색: 확장자(.txt) 포함 여부와 무관하게 정확하게 검색됩니다.
• 한글 자모 NFC 완벽 호환: Mac(NFD)과 Windows(NFC) 환경 간 한글 분리 현상 없이 모든 검색어가 100% 매끄럽게 일치합니다.
• 일치 글자 하이라이트 & 원클릭 지우기: 일치하는 글자가 눈에 띄게 강조되며, 검색창 우측 [×] 버튼이나 Esc 키로 즉시 검색을 초기화할 수 있습니다.
• 파일/폴더 마우스 드래그 앤 드롭 이동: 좌측 탐색기에서 파일이나 폴더를 마우스로 끌어서 다른 폴더 위로 놓으면 즉시 이동됩니다. 빈 공간에 놓으면 최상위 폴더로 이동합니다.
• 파일 보기 필터 전환: 상단 [txt 전용 / 전체 파일] 버튼으로 텍스트 메모만 보거나, 엑셀, PDF, 이미지 등 모든 파일을 확인할 수 있습니다.
• 인라인 관리 버튼: 항목에 마우스를 올리면 새 메모(+📝), 새 폴더(+📁), 이름 변경(✏️), 삭제(🗑️) 버튼이 나타납니다.
• 안전한 이름 변경 (EPERM 방어): 파일이 열려 있거나 백그라운드 인덱싱 중인 폴더도 잠금 대기 및 안전 복사 메커니즘을 통해 오류 없이 매끄럽게 변경됩니다.

2. 🔍 전체 본문 내용 검색 (신규)
• 단축키: Ctrl + Shift + F (Mac: Cmd + Shift + F)
• 상단 [편집 ▾] / [도구 ▾] 메뉴의 [전체 본문 검색] 또는 좌측 상단 [본문 내용] 탭 클릭으로 언제든 실행할 수 있습니다.
• 폴더 내 모든 텍스트 파일의 본문 내용을 초고속으로 전수 조사하여 검색어가 포함된 파일, 행 번호, 문맥 미리보기를 일목요연하게 표시합니다.
• 검색 결과 항목을 클릭하면 해당 메모가 즉시 에디터에 열리며, 일치하는 줄 위치로 자동 스크롤되고 검색 단어가 선택/하이라이트됩니다.

3. 🎨 스마트 하이라이트 & 텍스트 탐색
• 찾기/바꾸기 단어 색상 강조: Ctrl + F (Mac: Cmd + F)로 검색 시 문서 내 모든 일치 단어가 선명한 골드/옐로우 색상으로 하이라이트되며, 현재 포커스된 단어는 진한 오렌지색으로 구별됩니다.
• 마우스 드래그 & 더블클릭 동일 글자 자동 하이라이트: 본문에서 특정 단어를 더블클릭하거나 마우스로 원하는 글자를 드래그 선택하면, 문서 전체에서 동일한 글자가 부드러운 스카이블루/시안 색상으로 즉시 동시 강조됩니다. (1글자부터 임의 구문까지 실시간 감지)

4. 🔎 글자 크기(폰트) 확대 / 축소 / 리셋
• 단축키: Ctrl + + (확대), Ctrl + - (축소), Ctrl + 0 (기본 크기 리셋) / Mac: Cmd
• 마우스 휠: Ctrl + 마우스 휠을 위/아래로 굴려 글자 크기를 부드럽게 실시간 조절 가능합니다.
• 상단 [도구 ▾] 메뉴에서도 글자 크기를 손쉽게 조절할 수 있습니다.
• 설정된 글자 크기는 브라우저에 자동 기억되며, 줄 번호와 하이라이트 위치도 글자 크기에 맞춰 오차 없이 완벽 정렬됩니다.

5. ⌨️ Tab 키 들여쓰기 & Shift+Tab 내어쓰기
• Tab: 단일 커서 위치에서 2칸 공백을 삽입하거나, 마우스로 여러 줄을 선택한 상태에서 누르면 선택된 모든 줄이 한꺼번에 2칸 들여쓰기됩니다.
• Shift + Tab: 현재 줄 또는 선택된 여러 줄 전체를 2칸씩 깔끔하게 내어쓰기(들여쓰기 취소)합니다.
• 모든 들여쓰기/내어쓰기는 Ctrl + Z (실행 취소)로 언제든 되돌릴 수 있습니다.

6. ☑️ 스마트 체크리스트 할 일 토글
• '- [ ]' 또는 '- [x]' (또는 '*', '+', '1.' 체크리스트 형태)로 작성된 줄을 마우스로 더블클릭하면 즉시 완료('[x]') 및 미완료('[ ]') 상태로 스마트 토글됩니다.
• 회의록, 투두리스트, 개인 일정 체크를 별도 수정 없이 더블클릭 한 번으로 간편하게 관리할 수 있습니다.

7. 🖨️ 메모 인쇄 및 PDF 저장
• 단축키: Ctrl + P (Mac: Cmd + P) 또는 상단 [도구 ▾] -> [메모 인쇄 / PDF 저장]
• 사이드바, 상단 헤더, 줄 번호, 하이라이트 등 화면 UI 요소를 모두 깔끔하게 배제하고 순수 메모 텍스트 내용만 최적화된 서식으로 용지 인쇄 및 PDF 저장이 가능합니다.

8. 🧭 상단 [편집 ▾] 및 [도구 ▾] 메뉴바
• 상단 헤더의 드롭다운 메뉴를 통해 마우스 클릭만으로 모든 편집/도구 기능을 손쉽게 사용할 수 있습니다.
• 편집 메뉴: 실행 취소(Ctrl+Z), 다시 실행(Ctrl+Y), 줄 위/아래 이동, 한 줄 삭제, 찾기/바꾸기, 전체 본문 검색, 전체 선택
• 도구 메뉴: 전체 본문 검색(Ctrl+Shift+F), 글자 크기 조절(확대/축소/리셋), 메모 인쇄(Ctrl+P), 링크 삽입(Ctrl+K), 줄 번호 토글, 자동 줄바꿈 토글, 파일 필터 전환, 작업 폴더 변경, 다크/라이트 테마 전환, 도움말(F1)

9. ✂️ 강력한 줄 편집 단축키
• 현재 줄 위로 이동: Ctrl + Alt + ↑ (또는 Alt + ↑) / Mac: Option + ↑
• 현재 줄 아래로 이동: Ctrl + Alt + ↓ (또는 Alt + ↓) / Mac: Option + ↓
• 한 줄 즉시 삭제: Ctrl + D (또는 Ctrl + Shift + K) / Mac: Cmd + D
  (커서 위치의 줄 또는 드래그 선택한 여러 줄이 통째로 삭제되며, Ctrl+Z로 즉시 복구 가능합니다.)

10. 🔗 메모 간 위키 링크 & 외부 파일 연동
• 본문에 [[메모이름]] 또는 [[폴더/메모이름]]을 작성하고 더블 클릭하면 해당 메모로 즉시 이동합니다.
• 웹 URL 링크 지원: [[https://naver.com]] 형태의 인터넷 주소도 더블 클릭 시 기본 웹 브라우저로 즉시 열립니다.
• 엑셀, PDF, 이미지 외부 파일 연동: [[매출보고서.xlsx]], [[설계도.pdf]] 링크를 더블 클릭하면 컴퓨터의 전용 프로그램(Excel, 아크로뱃 리더 등)으로 즉시 실행됩니다.
• 상단 [링크 삽입] (Ctrl + K) 버튼으로 원하는 메모나 외부 파일을 검색하여 손쉽게 삽입할 수 있습니다.

11. 💾 실시간 스마트 자동 저장 & 안전 종료
• 글을 작성하면 1초 유휴 시(또는 연속 타이핑 시 3초 주기) 백그라운드에서 파일에 안전하게 자동 저장됩니다.
• 원본과 내용이 동일할 경우 불필요한 저장이 일어나지 않으며, 우측 상단 상태 인디케이터에서 '저장됨' 상태와 최종 수정 시간을 실시간으로 확인합니다.
• 장시간 켜두거나 최소화/절전 모드로 두어도 서버 연결이 끊기지 않으며, 창 닫기(X) 시에만 안전하게 자동 종료됩니다.

12. 🔢 줄 번호, 자동 줄바꿈 & 방문 기록 탐색
• 하단 상태바의 [줄 번호] (Alt + L) 및 [자동 줄바꿈] (Alt + Z) 버튼으로 보기 방식을 언제든 토글할 수 있습니다.
• 웹 브라우저처럼 상단 [◀] / [▶] 버튼이나 단축키(Alt + ← / →)로 최근 열람한 메모들을 앞뒤로 자유롭게 탐색할 수 있습니다.

13. 🌓 다크 모드 / 라이트 모드
• 좌측 상단 [🌙] / [☀️] 버튼으로 언제든 테마를 전환할 수 있으며 설정은 자동 저장됩니다.

⌨️ 키보드 단축키 모음

• 전체 본문 내용 검색: Ctrl + Shift + F (Mac: Cmd + Shift + F)
• 단어 찾기 (Find): Ctrl + F (Mac: Cmd + F)
• 단어 바꾸기 (Replace): Ctrl + H (Mac: Cmd + H)
• 글자 크기 확대: Ctrl + + 또는 Ctrl + 마우스 휠 위 (Mac: Cmd + +)
• 글자 크기 축소: Ctrl + - 또는 Ctrl + 마우스 휠 아래 (Mac: Cmd + -)
• 글자 크기 리셋: Ctrl + 0 (Mac: Cmd + 0)
• 들여쓰기 (2칸): Tab (여러 줄 블록 들여쓰기 지원)
• 내어쓰기 (2칸 취소): Shift + Tab (여러 줄 블록 지원)
• 체크리스트 상태 토글: '- [ ]' 또는 '- [x]' 줄 더블클릭
• 메모 인쇄 / PDF 저장: Ctrl + P (Mac: Cmd + P)
• 한 줄 삭제: Ctrl + D 또는 Ctrl + Shift + K (Mac: Cmd + D)
• 현재 줄 위로 이동: Ctrl + Alt + ↑ 또는 Alt + ↑ (Mac: Option + ↑)
• 현재 줄 아래로 이동: Ctrl + Alt + ↓ 또는 Alt + ↓ (Mac: Option + ↓)
• 메모 즉시 저장: Ctrl + S (Mac: Cmd + S)
• 줄 번호 켜기/끄기: Alt + L (Mac: Option + L)
• 자동 줄바꿈 켜기/끄기: Alt + Z (Mac: Option + Z)
• 메모 링크 삽입: Ctrl + K (Mac: Cmd + K)
• 새 메모 생성: Ctrl + N (Mac: Cmd + N)
• 작업 폴더 변경: Ctrl + O (Mac: Cmd + O)
• 이전 메모로 뒤로가기: Alt + ← (Mac: Option + ← 또는 Cmd + [)
• 다음 메모로 앞으로가기: Alt + → (Mac: Option + → 또는 Cmd + ])
• 기능 안내 / 도움말: F1
